# v4：交互请求缓存修复与证据验收

本轮实现缓存预测修复、逐档失配诊断和人工证据清单。没有新增付费模型调用，也没有修改业务项目或原生产账本中的历史记录。

## 原因与证据

上一轮使用 API 请求日志中的 shape、params、消息 blob 重建请求，遗漏了 Claude Code 在发送时加入的字段。因此旧样本离线成功，不能证明真实请求预测正确。

使用本机 Claude Code **2.1.327**、独立配置目录、假凭据、合成文件和 loopback 模拟上游，分别检查 print 与交互入口。交互请求包含 `safeguards`；其中 `dangerous_tool_use.classifier_context` 是工具安全分类上下文，可能包含按工具调用累积的 `prior_turn_context`。旧预测器把整个字段当成生成提示参数，放进所有内容块之前的哈希种子。

再对照一段本地会话 中记录的 `serverClassifierContext` 与账本：

| 后续主请求 | 工具分类历史上下文变化 | 实际 v3 缓存预测 |
| --- | --- | --- |
| 20 次 | 新增上下文 | 全部预测为 0，但上游实际命中 |
| 5 次 | 没有新增上下文 | 全部预测到了命中 |

25 次后续请求的对应关系完全一致。首条请求本地冷启动另计。Flash 会话第一次后续请求的单次漏预测没有足够旧日志确定具体字段，不将它一并宣称解决；新诊断用于继续核验。

## 修复边界

- 仅对已识别的 `dangerous_tool_use` 且 `classifier_context.v == 1`，在**本地预测**中排除 `classifier_context`，并从生成输入长度的估算中排除其字节。
- 上游请求仍只替换顶层 `model`，完整保留安全字段、权限上下文、签名、工具参数和消息。回归测试逐字核对转发结果。
- safeguard 类型、其他字段、未知版本，以及真正的 thinking 参数、工具、系统提示和消息变化仍参与缓存指纹，避免把所有未知字段都忽略。
- 决策保存两档 `high_cache_diagnostic` / `low_cache_diagnostic`，包含本地证据量、存活证据、匹配数量、回看范围、分层变化和分类上下文变化。实际响应后另记录缓存证据是否更新。正文与权限内容不写入统计。
- 预测版本为 `block-prefix-v4`，本地配置策略为 `v4`，旧记录按旧版本展示。

## 验证结果与限制

1. **完整回归、race、静态检查及构建通过。** 新测试覆盖已知元数据变化、未知 safeguard 类型/版本、真实系统/参数变化、转发字节保留、诊断信息不泄漏正文、端到端缓存记录，以及质量清单校验。
2. **真实 CLI 请求结构测试**：本地交互测试捕获的 6 条请求离线重放，5 次后续请求均有缓存预测。此测试使用合成 usage，验证结构和状态维护，不代表供应商的真实命中率。
3. **补全历史分类上下文后的重放**：新 Opus 会话前 16 条请求的消息哈希完整可验证，恢复日志中的历史分类上下文后，原记录的 11 次漏预测在 v4 中为 0 次。实际缓存读量 862,605 token，预测 690,079 token；保留八折预测，绝对误差从 636,940 降到 172,526 token。
4. 第 17 条起有一条历史消息无法通过现有日志完整还原，因此没有伪造后续 10 条请求来计算“全会话修复率”。未重新调用真实模型；最终线上效果以升级后新请求的诊断为准。
5. 页面验证使用生产账本副本、一个合成任务及假上游。验证了质量清单加载、缺少证据时拒绝保存、失败优先于未确定、记录保存和统计，以及 390px 页面无横向溢出。

本地诊断文件在 `/private/tmp/tier-router-v4-capture/`，包含本机协议捕获和私有历史重建材料，不纳入版本控制。可选离线测试：

## 质量验收

页面新增三套标准，均保存标准版本、逐项结果和证据：

| 标准 | 检查内容 |
| --- | --- |
| 函数 / API 解释 | 签名约束、超时/重试/取消语义、示例验证、版本与引用 |
| 并发 / 死锁分析 | 触发与等待路径、异常与取消路径、复现证据、结论边界 |
| 代码修改 | 需求行为、相关测试、边界回归 |

所有项通过才通过；任一项失败则失败；存在未确定项且无失败时，总结果为未确定。缺项、重复项、缺证据、标准版本冲突或试图强行指定矛盾总结果，均由后端拒绝。旧的快速人工反馈仍可使用，单独区分于带证据清单的评价。

这是**人工提供证据的验收机制**，不自动执行用户填写的命令、不读取任意证据路径、不调用模型给自己打分。HTTP 200、缓存命中和模型价格均不能代替质量验收。

解释题的示例应编译，并与指定版本的 SDK 文档核对。并发题需要验证触发条件和等待路径；未执行的检查应保留“未确定”。私有业务项目和回答的具体内容不随本报告发布。

## 使用

重启现有启动命令，并用新会话测试。统计页面应显示 `自动路由 · v4`。请求详情能区分“没有本地证据”“证据过期”“前缀变化”“超出回看范围”；任务“评价”中选择验收标准后逐项填写证据。原币种费用、6.8 固定汇率和使用占比统计延续原配置。
